# College Lab Codes

I'm Shlok Verma, a Data Science & Engineering undergraduate at MIT Manipal,
currently in my third year. This repository holds all of my college lab work, and
I keep adding to it as I go - second year is here now, third year follows as I do
it, and first year will be added once I have tidied those files up. It keeps
growing until I graduate.

Everything is readable on its own: every lab folder has its own README explaining
what the code does, how to build it and what it needs, with the lab manual
alongside it. Code is organised by year, then semester, then lab, preserving the
structure it was written in. Compiled output, dependency trees and vendored SDKs
are left out; everything here is source, written notes or the data the programs
operate on.

**Juniors and fellow students: this is here for you.** Use it, read it, borrow
from it, take it apart to see how it works. I put it out in the open because
working these labs out alone is harder than it needs to be. All I ask is that you
understand what you hand in - your evaluation goes better that way, and your
institution has its own rules about copied submissions.
