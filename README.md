# College Lab Codes

I'm Shlok Verma, a Data Science & Engineering undergraduate at MIT Manipal.
This repository is my second-year laboratory coursework, kept in one place so the
work is readable on its own: every lab folder has its own README explaining what
the code does, how to build it and what it needs, with the lab manual alongside it.

Code is organised by year, then semester, then lab, preserving the structure it
was written in. Compiled output, dependency trees and vendored SDKs are left out;
everything here is source, written notes or the data the programs operate on.

Uploaded a unit at a time: 1 of 18 so far.

## Labs

| Semester | Lab | Topics |
| --- | --- | --- |
| Sem 3 | [Data Structures Lab](Year-II/Sem-3/DS-Lab) | Pointers, dynamic memory, linked lists, stacks, queues, sorting, binary search trees |
